# J-функция: расчёт SWn, J(Sw) и коэффициентов a, b

Программа на Python для расчёта по лабораторным данным керна:

- **J(Sw)** — J-функция Леверетта для каждой точки измерения каждого образца;
- **SWn** — нормализованная водонасыщенность;
- **a, b** — коэффициенты экспоненциального тренда `J(Sw) = a * exp(b * SWn)`,
  подбираемые методом наименьших квадратов (как требуется для Petrel).

Формулы и логика полностью повторяют вашу методику из файла
`J-Function_Gran.xlsx` (лист `ZH2026(аналог Грана)`) — расчёт был
проверен построчно на ваших данных, и результат **«Все образцы»**
(n=742, a=13.0015, b=-4.6225) совпал с Excel до 5-го знака после запятой.

## 2. Подготовка исходных данных

Программа принимает **"длинную" таблицу**: одна строка = одна точка
измерения (один Sw и одно Pc) для одного образца. Файл может быть `.csv`
или `.xlsx`.

Обязательные столбцы:

| Столбец         | Описание                                    |
|-----------------|----------------------------------------------|
| `Sw`            | водонасыщенность образца, д.ед. (0..1)       |
| `Pc_lab_MPa`    | капиллярное давление в лаборатории, МПа      |
| `porosity_pct`  | пористость образца, %                        |
| `perm_mD`       | проницаемость образца, мД                    |

Желательные столбцы (без них программа тоже посчитает J и SWn, но
не сможет группировать результаты и правильно определять Swir):

| Столбец   | Описание                                            |
|-----------|------------------------------------------------------|
| `well`    | номер скважины                                       |
| `sample`  | номер образца (нужен, чтобы отличать образцы друг от друга) |
| `horizon` | пласт/горизонт (Мел, Юра и т.п.) — по нему считаются отдельные a, b |

Необязательный столбец `Swir` — если вы уже знаете остаточную
водонасыщенность образца и не хотите, чтобы программа определяла её
автоматически (по умолчанию берётся Sw в точке с максимальным Pc для
данного образца — как в вашем Excel).

Пример такого файла на основе ваших же данных лежит в
`examples/lab_data_example.csv`.

## 3а. Графическое приложение (просто: загрузили файл — увидели график)

Если не хочется работать с командной строкой каждый раз — есть окно с
кнопками, как в привычных программах:

```
python run_gui.py
```

Откроется окно:

1. Нажмите **"Загрузить данные..."** и выберите свой файл (`.csv` или `.xlsx`,
   формат столбцов — как в разделе 2).
2. Программа сама посчитает Pc(рез), SWn, J(Sw), подберёт коэффициенты
   `a, b` и сразу построит график — ничего больше нажимать не нужно.
3. Вверху появится готовая формула: `J(SWn) = a·exp(b·SWn)` с текущими
   a, b, количеством точек n и качеством подгонки R².
4. Выпадающие списки **"Скважина"** и **"Горизонт"** позволяют
   пересчитать a, b и график только по нужной скважине/горизонту.
5. Вкладка **"Таблица точек"** показывает исходные и рассчитанные
   значения построчно.
6. Кнопка **"Экспортировать результаты..."** сохраняет текущий
   (отфильтрованный) результат в Excel в выбранную папку.

python run.py --input examples/lab_data_example.csv --output-dir results

После запуска в папке `results/` появятся:

### Настройка констант J-функции

Если для ваших данных отличаются угол смачивания/поверхностное
натяжение или переводной коэффициент, задайте их флагами:

```
python run.py --input data.csv --output-dir results \
    --theta-lab 30 --gamma-lab 48 --theta-res 30 --gamma-res 30 --coeff 3.183
```

Это значения по умолчанию (взяты из вашего файла). Флаг `--group-col`
позволяет группировать не по `horizon`, а по любому другому столбцу
(например `well`), либо отключить группировку (`--group-col ""`).

## 4. Как это устроено внутри (формулы)

```
Pc(рез)[атм] = Pc_lab[МПа] * 9.8692327 * (γ_рез·cosθ_рез) / (γ_лаб·cosθ_лаб)

J(Sw) = coeff * Pc(рез) * sqrt(perm_mD / (porosity_pct/100)) / (γ_рез·cosθ_рез)

SWn = (Sw - Swir) / (1 - Swir)
```

Коэффициенты `a, b` находятся линеаризацией: `ln(J) = ln(a) + b·SWn`,
методом наименьших квадратов по всем точкам, где `J > 0`.

Код разбит на модули в папке `jfunction/`:

- `calc.py` — формулы Pc(рез), J, SWn;
- `fit.py` — МНК-регрессия для a, b (+ R² для оценки качества тренда);
- `io.py` — чтение CSV/XLSX с исходными данными;
- `report.py` — сохранение таблиц и построение графика.

## 6. Важное замечание про разбивку по горизонтам (Мел/Юра)

Результат **«Все образцы»** (n=742, a≈13.00, b≈-4.62) точно
воспроизводит то, что было в вашем Excel. А вот отдельные a,b по
горизонтам «Мел»/«Юра» в исходном файле были посчитаны по не совсем
полному диапазону данных (в вашем же файле, на листе "Claude Log",
есть пометка, что это стоит уточнить) — сумма n по Мел+Юра там меньше,
чем n "Все образцы". Программа считает a,b по горизонтам **по всем**
точкам этого горизонта, поэтому числа по Мел/Юра будут немного
отличаться от старых ячеек в Excel — это ожидаемо и является более
полным/корректным расчётом.
