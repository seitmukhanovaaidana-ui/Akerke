# J-функция: расчёт SWn, J(Sw) и коэффициентов a, b

Программа на Python для расчёта по лабораторным данным керна:

- **J(Sw)** — J-функция Леверетта для каждой точки измерения каждого образца;
- **SWn** — нормализованная водонасыщенность;
- **a, b** — коэффициенты экспоненциального тренда `J(Sw) = a * exp(b * SWn)`,
  подбираемые методом наименьших квадратов (как требуется для Petrel).

Формулы и логика полностью повторяют вашу методику из файла
`J-Function_Gran.xlsx` (лист `ZH2026(аналог Грана)`) — расчёт был
проверен построчно на ваших данных, и результат **«Все образцы»**
(n=742, a=13.0015, b=-4.6225) совпал с Excel до 5-го знака после запятой.

## 2. Подготовка исходных данных

Программа принимает **"длинную" таблицу**: одна строка = одна точка
измерения (один Sw и одно Pc) для одного образца. Файл может быть `.csv`
или `.xlsx`.

Обязательные столбцы:

| Столбец         | Описание                                    |
|-----------------|----------------------------------------------|
| `Sw`            | водонасыщенность образца, д.ед. (0..1)       |
| `Pc_lab_MPa`    | капиллярное давление в лаборатории, МПа      |
| `porosity_pct`  | пористость образца, %                        |
| `perm_mD`       | проницаемость образца, мД                    |

Желательные столбцы (без них программа тоже посчитает J и SWn, но
не сможет группировать результаты и правильно определять Swir):

| Столбец   | Описание                                            |
|-----------|------------------------------------------------------|
| `well`    | номер скважины                                       |
| `sample`  | номер образца (нужен, чтобы отличать образцы друг от друга) |
| `horizon` | пласт/горизонт (Мел, Юра и т.п.) — по нему считаются отдельные a, b |

Необязательный столбец `Swir` — если вы уже знаете остаточную
водонасыщенность образца и не хотите, чтобы программа определяла её
автоматически (по умолчанию берётся Sw в точке с максимальным Pc для
данного образца — как в вашем Excel).

Пример такого файла на основе ваших же данных лежит в
`examples/lab_data_example.csv`.

### Можно загружать "сырой" перенос отчёта лаборатории в Excel

Если у вас Excel-файл, куда данные просто перенесены из лабораторного
отчёта как есть - по одному блоку на образец (строка "Исходные данные
образца №...", дальше таблица "Наименование/Значение" вперемешку со
столбцами Sw/Pc), а не готовая "длинная" таблица - грузите его как есть,
программа сама распознает такой формат и разберёт его:

```
python run.py --input сырые_данные.xlsx --output-dir results
```

Определяется это автоматически: если в файле нет привычных столбцов
(Sw, Pc_lab_MPa, ...), программа сама поищет блоки образцов и горизонт
(если он проставлен), как при чтении Word-отчёта ниже.

### Можно загружать сразу "сырой" отчёт лаборатории (.docx)

Если лаборатория присылает результаты в виде Word-документа (таблицы вида
"Наименование / Значение / Sw / Капиллярное давление ..." по одному образцу) -
такой файл можно скормить программе напрямую, без переноса в Excel/CSV:

```
python run.py --input отчёт_лаборатории.docx --output-dir results
```

Программа сама найдёт в документе все таблицы образцов, вытащит Sw, Pc,
пористость, проницаемость, номер скважины и образца. Горизонта (Мел/Юра)
в таком отчёте обычно нет - это можно указать отдельно, вручную добавив
столбец `horizon`, если он нужен для группировки.

Это было проверено на реальном отчёте: результат "Все образцы" (n=742,
a=13.0015, b=-4.6225), посчитанный **прямо из Word-файла**, без какого-либо
ручного переноса в Excel, точно совпал с тем, что было в исходном
Excel-файле.

## 3а. Графическое приложение (просто: загрузили файл — увидели график)

Если не хочется работать с командной строкой каждый раз — есть окно с
кнопками, как в привычных программах:

```
python run_gui.py
```

Откроется окно:

1. Нажмите **"Загрузить данные..."** и выберите свой файл (`.csv` или `.xlsx`,
   формат столбцов — как в разделе 2).
2. Программа сама посчитает Pc(рез), SWn, J(Sw), подберёт коэффициенты
   `a, b` и сразу построит график — ничего больше нажимать не нужно.
3. Вверху появится готовая формула: `J(SWn) = a·exp(b·SWn)` с текущими
   a, b, количеством точек n и качеством подгонки R².
4. Выпадающие списки **"Скважина"** и **"Горизонт"** позволяют
   пересчитать a, b и график только по нужной скважине/горизонту.
5. Вкладка **"Таблица точек"** показывает исходные и рассчитанные
   значения построчно.
6. Кнопка **"Экспортировать результаты..."** сохраняет текущий
   (отфильтрованный) результат в Excel в выбранную папку.
7. Панель **"Сравнение трендов на графике"** — жмёте "Закрепить текущий
   тренд" при разных фильтрах/константах, и все закреплённые варианты
   остаются на графике пунктиром для визуального сравнения.
8. Вкладка **"Типы пород (k-φ)"** — кроссплот пористость-проницаемость
   и разбиение образцов на классы по проницаемости (границы задаются
   вручную, например `1, 10, 100` мД): для каждого класса считаются
   свои a, b и R². Это полезно, когда общий тренд по всем образцам
   получается с невысоким R² — часто это значит, что в выборке
   смешаны разные типы породы, и по отдельности для каждого типа
   тренд ложится намного точнее.

### Вкладка "ОФП (Кори)" — расчёт степеней Кори по данным ОФП

Рядом с вкладкой "J-функция" есть отдельная вкладка **"ОФП (Кори)"** —
она не связана с J-функцией и работает с другим типом лабораторных
данных: относительными фазовыми проницаемостями (ОФП, krw/krow от Sw).

1. Нажмите **"Загрузить ОФП-отчёт (.docx)..."** и выберите Word-отчёт
   лаборатории по ОФП (вида "Данные проведённого эксперимента по
   определению ОФП" - таблица метаданных образца + таблица
   Qнефти/Qводы/Sw/krw/krow).
2. Программа сама найдёт в документе все образцы (по скважинам и
   моделям), для каждого посчитает степени Кори методом наименьших
   квадратов (линеаризация без свободного члена, как в исходном
   Excel-файле, лист "Параметризация_Кори"):

   ```
   Sw*  = (Sw - Swir) / (Swmax - Swir)
   Krw* = krw / krwmax
   Kro* = krow / krow_swc

   ln(Krw*)     = nw  * ln(Sw*)        =>  Krw* = Sw*^nw
   ln(1 - Sw*)      = ...
   ln(Kro*)     = now * ln(1 - Sw*)    =>  Kro* = (1-Sw*)^now
   ```

3. Таблица справа показывает nw, now и R² для каждого образца
   отдельно, а панель **"Единые параметры Кори (по керну)"** -
   nw/now (медиана по образцам) и Swir/Sor/krwmax (среднее по
   образцам) для всей выборки сразу, а также R²_w/R²_o - насколько
   хорошо эти единые nw/now ложатся сразу на ВСЕ точки выборки.
4. На графике - точки krw/krow(Sw) по всем образцам (цвет - по
   скважине) и единая кривая Кори, построенная по единым nw/now.
5. Кнопка **"Экспортировать результаты..."** сохраняет таблицу точек,
   таблицу коэффициентов по образцам и график в выбранную папку.
6. Галочка **"Задать nw, now вручную"** - как и в J-функции, позволяет
   самостоятельно подобрать nw/now ползунками или вводом числа и сразу
   увидеть, как меняются кривая на графике и R²_w/R²_o (по всем
   точкам сразу) - удобно, чтобы вручную скоррелировать единую кривую,
   если автоматическая медиана вас не устраивает. Снятие галочки
   возвращает автоматическую медиану.

Если в отчёте один и тот же керн измерен как два образца в одной
метаданные-таблице (два блока Qнефти/Qводы/Sw/krw/krow подряд), им
присваиваются id вида `305-2` и `305-2b`. Если в какой-то из таблиц
данные повреждены (например, перепутан порядок строк) - такой образец
пропускается при расчёте степеней Кори (не портит общий результат),
но остаётся видимым на графике как есть - это разумный сигнал
проверить его в исходном отчёте.

### Настройка констант J-функции

Если для ваших данных отличаются угол смачивания/поверхностное
натяжение, переводной коэффициент или степени при пористости/
проницаемости, задайте их флагами:

```
python run.py --input data.csv --output-dir results \
    --theta-lab 30 --gamma-lab 48 --theta-res 30 --gamma-res 30 --coeff 3.183 \
    --perm-power 0.5 --poro-power 0.5
```

Это значения по умолчанию (взяты из вашего файла). `--perm-power` и
`--poro-power` соответствуют полям **"Power for permeability term"** и
**"Power for porosity term"** на вкладке "J-function parameters" в
Petrel: по умолчанию обе равны 0.5, что даёт классическую формулу
Леверетта (квадратный корень); если в Petrel эти степени изменены -
укажите те же значения здесь, иначе a, b не будут соответствовать
формуле, которую реально использует Petrel. Флаг `--group-col`
позволяет группировать не по `horizon`, а по любому другому столбцу
(например `well`), либо отключить группировку (`--group-col ""`).

## 4. Как это устроено внутри (формулы)

```
Pc(рез)[атм] = Pc_lab[МПа] * 9.8692327 * (γ_рез·cosθ_рез) / (γ_лаб·cosθ_лаб)

J(Sw) = coeff * Pc(рез) * perm_mD^perm_power / (porosity_pct/100)^poro_power
              / (γ_рез·cosθ_рез)

SWn = (Sw - Swir) / (1 - Swir)
```

При `perm_power = poro_power = 0.5` (по умолчанию) это в точности
классическая формула Леверетта `sqrt(perm_mD/(porosity_pct/100))`.

Коэффициенты `a, b` находятся линеаризацией: `ln(J) = ln(a) + b·SWn`,
методом наименьших квадратов по всем точкам, где `J > 0`.

Код разбит на модули в папке `jfunction/`:

- `calc.py` — формулы Pc(рез), J, SWn;
- `fit.py` — МНК-регрессия для a, b (+ R² для оценки качества тренда);
- `io.py` — чтение CSV/XLSX с исходными данными;
- `report.py` — сохранение таблиц и построение графика.

## 6. Важное замечание про разбивку по горизонтам (Мел/Юра)

Результат **«Все образцы»** (n=742, a≈13.00, b≈-4.62) точно
воспроизводит то, что было в вашем Excel. А вот отдельные a,b по
горизонтам «Мел»/«Юра» в исходном файле были посчитаны по не совсем
полному диапазону данных (в вашем же файле, на листе "Claude Log",
есть пометка, что это стоит уточнить) — сумма n по Мел+Юра там меньше,
чем n "Все образцы". Программа считает a,b по горизонтам **по всем**
точкам этого горизонта, поэтому числа по Мел/Юра будут немного
отличаться от старых ячеек в Excel — это ожидаемо и является более
полным/корректным расчётом.
